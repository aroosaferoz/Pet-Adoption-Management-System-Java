# 🐾 Pet Adoption Management System

A desktop-based Java application built using **Java Swing** and developed in **NetBeans IDE**.  
This system allows admins to manage pets, adopters, and adoption requests in an organized way.

---

## 📌 Features

### 🔐 Authentication
- User Login  
- New User Signup  
- Basic validation for secure access

### 🐕 Pet Management
- Add new pets  
- Update pet details  
- Delete pets  
- View full list of pets  
- Store and load data using file handling

### 👤 Adopter Management
- Register adopters  
- View adopter list  
- Edit or remove adopter information

### 📄 Adoption Request Handling
- Create adoption requests  
- Approve or reject requests  
- Track request status

### 📁 File Handling Support
All data (pets, adopters, requests) is stored in **.txt files** using:
- `FileUtils.java`

### 🖥️ User Interface
- Simple and clean Java Swing UI  
- Multiple forms such as:
  - `LOGIN.java`
  - `SIGNUP.java`
  - `Dashboard.java`
  - `PetManagement.java`
  - `AdopterManagement.java`
  - `AdoptionRequest.java`

## 🚀 How to Run

1. Download or clone the repository  
2. Open **NetBeans IDE**
3. Import the project  
4. Clean & Build  
5. Run the `LOGIN.java` file to start the system
